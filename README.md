# Cipher

A public archive system for Bluesky collections (starter packs, blocklists, and curated lists). Cipher periodically fetches public collection data from AT Protocol Personal Data Servers (PDS) and compiles them into a searchable, browsable static website.

## Prerequisites

- Python 3.7+
- `requests` library: `pip install requests`
- Internet connection (to fetch data from PDS)
- Make (optional, for automated builds)

## Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd cipher
   ```

2. **Install Python dependencies:**
   ```bash
   pip install requests
   ```

3. **Configure the source account:**
   
   Edit the fetch scripts in `scripts/` to point to your desired source account. By default, they fetch from `gothicwtf.eurosky.social`:
   
   ```python
   target_handle = "gothicwtf.eurosky.social"  # Change this
   pds_host = "eurosky.social"                 # Change this
   ```

## Usage

### Quick Start (with Make)

From the project root:

```bash
# Fetch latest data and regenerate site
make compile

# Clean all generated files
make clean

# Show help
make help
```

### Manual Usage

If you prefer to run scripts individually:

```bash
cd scripts/

# Fetch collections (in any order)
python3 fetch_starter_packs.py
python3 fetch_blocklists.py
python3 fetch_curated_lists.py
python3 fetch_custom_feeds.py

# Generate site files
python3 generate_site.py
```

This will create:
- `markdown/*.md` - Raw data files (gitignored)
- `data.json` - Compiled data for the website (gitignored)
- `site.html` - The complete website (gitignored)

### View Locally

Open `site.html` in your browser. Note that due to CORS restrictions, you'll need to serve it via a local web server to load `data.json`:

```bash
# Python 3
python3 -m http.server 8000

# Then open http://localhost:8000/site.html
```

## Deployment

Upload both files to your web server:
- `site.html` - The website
- `data.json` - The data (must be in the same directory!)

Both files must be in the same directory for the site to work.

## Automated Updates

### Cron Setup

To automatically refresh data weekly:

```bash
# Edit your crontab
crontab -e

# Add this line (runs every Sunday at 2 AM):
0 2 * * 0 cd /path/to/cipher && make compile >> cipher-$(date +\%Y-\%m-\%d).log 2>&1
```

The logs are automatically gitignored (`*.log`).

### What Gets Updated

- All public collections from the source account
- Statistics (member counts, collection counts)
- "Last Updated" date on the website

### Rate Limiting

- Scripts include 0.1s delays between requests
- Weekly updates are well within safe limits
- No authentication required
- PDS endpoints are designed for public access

## Customization

### Styling

The site uses NHCarrigan's global style guide. To customize:

1. Edit the CSS in `scripts/generate_site.py`
2. Run `make compile` to regenerate `site.html`

### Source Account

To archive a different Bluesky account:

1. Edit all `fetch_*.py` scripts in `scripts/`
2. Update `target_handle` and `pds_host`
3. Update the HTML reference in `generate_site.py` (line ~526)
4. Run `make compile`

## Troubleshooting

### "Failed to load data"

- Ensure `data.json` and `site.html` are in the same directory
- Check browser console for CORS errors
- Serve via HTTP (not file://) to avoid CORS issues

### Script fails with 401/403

- The PDS might be temporarily unavailable
- Check if the source account is still active
- Verify the PDS host is accessible

### No collections found

- Verify the source account has public collections
- Check that the handle and PDS host are correct
- Ensure the account isn't suspended or deleted
